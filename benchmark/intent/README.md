# Intent Benchmark

Purpose:
Evaluate the Intent Model's ability to extract structured information from
natural language origami requests.

Difficulty Levels

- easy
  - Explicit language
  - Single object
  - Few modifiers

- medium
  - More descriptive language
  - Multiple attributes
  - More vague language

Evaluation

The "expected" field inside each test case is the ground truth ("golden output").

The evaluator compares the model output against the golden output.
